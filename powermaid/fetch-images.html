Powermaid Image Extractor

This tool fetches all images from powermaid.com.br and saves the URL mapping. Open this file in your browser and click "Start".

Instructions

  1. Click "Start Extraction" below
  2. The tool will load each Powermaid page and extract image URLs
  3. Once done, click "Download Mapping" to save image-mapping.json
  4. Place the JSON file in the powermaid/ folder
  5. Run: node update-html.js to update your HTML files
  6. Alternatively, click "Download All Images" to save a zip of all images
